# test 평가 고정 프로토콜 v2.2 (최종 제안 선택 규칙)

공식 test 데이터를 받기 **전에** 작성했다. 이 문서는 두 번 커밋한다.
1. **규칙만** 먼저 커밋한다(train 후보 계산 전).
2. train으로 후보를 계산해 고른 결과를 아래 "선택 결과"에 적고 커밋한 뒤 git 태그 `test-protocol-v2.2`를 붙인다.

v1, v2, v2.1은 그대로 두고 실행도 그대로 한다. 이 문서는 **최종 제안 하나를 고르는 규칙과 그 판정**만 더한다.

실행: `python scripts/40_test_evaluate_v2_2.py <test 파일>` (v1, v2.1을 먼저 계산하고 v2.2를 덧붙인다)
예행연습: `python scripts/40_test_evaluate_v2_2.py --dry-run`

## 왜 개정하나

팀원 검토(이교민)에서 다음 지적이 나왔다. "과제의 목표는 Sharpe 최대화로 주어져 있다. 그러면 Sharpe의 계산 기준과 선별 단위를 고정하고, 그 기준으로 전략과 승인비율을 정한 뒤 test에서 확인해야 한다."

지금까지는 승인 30%·50%를 대표 조건으로 비교만 했고, "그래서 무엇을 몇 % 승인하나"라는 최종 답을 정하지 않았다. 그런데 train에서 Sharpe가 가장 높은 조합을 그냥 고르면 사후 선택이 된다. 그래서 **고르는 방법을 먼저 고정하고**, 그 방법을 train에 한 번 적용해 나온 답을 test에서 한 번만 확인한다.

이미 본 것도 적어 둔다. train에서 승인 30%·50%의 V1·V2 포트폴리오 Sharpe는 38단계에서 이미 봤다. 나머지 승인비율은 발행월 컷으로 계산한 적이 없다.

## 1. 주 지표 (고정)

**발행월 포트폴리오 Sharpe.** 매달 투자금을 승인 대출과 국채에 나눠 넣는다고 본다. 그달의 초과수익은 (승인 금액 비중) × (승인 묶음 IRR − 허들)이다. 48개월의 평균을 표준편차로 나눈다. 수수료는 1%다.

- **선별 단위:** 발행월마다 그달 대출 중 상위 q를 자른다. 동점은 아주 작은 무작위 값으로 끊는다.
- **허들(선택용):** 같은 달 같은 만기 국채. Sharpe의 정의가 무위험 수익률 대비 초과수익이기 때문이다. 국채 +1%p, +2%p, BAA 결과는 보고만 한다(v2.1 해석 규칙 6).
- **표본:** 2013~16년 발행 36개월 대출. as-of 모델의 p를 쓴다(train은 30단계와 같은 `ev`).

건별 Sharpe(거절 = 0)는 승인비율만 줄여도 값이 바뀌어 선택 기준으로 쓰지 않는다. 건별 Sharpe(승인만)는 조교 기준(0.2~0.4)과 크기를 맞춰 보는 용도로 보고만 한다.

## 2. 후보 (고정)

- **전략:** V1 기대수익 순, V2 부도확률 낮은 순.
- **승인비율:** 10, 20, …, 90%.
- 후보는 이렇게 18개다.

V3 단순 규칙(등급 안에서 계좌 개설이 적은 순)은 **후보에서 뺀다.** train을 보고 고른 규칙이라, 후보에 넣으면 사후 선택이 두 번 겹친다. V3는 v2.1의 H7로 따로 검증하고, 같은 승인비율에서 도전자로 보고한다.

## 3. 선택 규칙 (고정, 1-SE 규칙)

1. train에서 18개 후보의 포트폴리오 Sharpe를 계산한다.
2. 각 Sharpe의 표준오차(SE)를 블록 부트스트랩으로 구한다. 블록은 6개월, 반복은 2000회, seed는 2026이다. 매 반복에서 같은 달 묶음을 모든 후보에 공통으로 쓴다.
3. 최고 Sharpe 후보의 값을 S\*, 그 SE를 SE\*라 한다. Sharpe가 S\* − SE\* 이상인 후보를 "최고와 구분되지 않는 후보"로 본다.
4. 그중 **승인비율이 가장 큰 후보**를 고른다. Sharpe는 규모를 무시하므로, 통계적으로 구분되지 않는다면 더 많이 승인해 금액과 NPV가 큰 쪽이 낫다. 또 모델 꼬리 부분에 덜 기대게 된다.
5. 승인비율이 같은 후보가 둘이면 Sharpe가 높은 쪽을 고른다.

이 규칙의 결과가 **최종 제안**이다. test를 본 뒤에는 바꾸지 않는다.

## 4. test 판정 (고정)

주 표본은 test의 2013~16년 36개월 종결 대출이다.

| 가설 | 지지 기준 |
|---|---|
| **H10 제안 유지** | 최종 제안의 포트폴리오 Sharpe에서 같은 승인비율 무작위(10회) 평균 Sharpe를 뺀 값의 90% 블록 부트스트랩 구간 하한이 0보다 크다 |
| H11 전부 승인 대비(보고) | 최종 제안의 Sharpe가 전부 승인(100%)의 Sharpe보다 높다 |
| H12 선택 후회(보고) | test에서 18개 후보 중 최종 제안의 순위와, 1위와의 Sharpe 차이를 보고한다. 판정하지 않는다 |

해석 규칙:

8. **H10이 실패하면 최종 제안을 철회한다.** "이 기간 test에서는 선별이 Sharpe를 무작위보다 올리지 못했다"고 그대로 보고한다. v2.1의 H5(등급 안 신호)는 별개로 판정한다.
9. **H12에서 다른 후보가 1위여도 제안을 바꾸지 않는다.** 1위와의 차이를 보고하고, 그 차이가 train의 SE\*보다 작으면 "구분되지 않는 차이"로 쓴다.
10. **V3가 test에서 최종 제안보다 Sharpe가 높아도 제안을 바꾸지 않는다.** H7 결과와 함께 "사후 규칙의 후속 검증 과제"로 보고한다.
11. 허들 4단계에서 최종 제안의 Sharpe와 초과수익을 모두 보고한다.

## 선택 결과 (train 2013~16, 이미 본 데이터라 증거 아님)

`scripts/39_final_choice.py`, 결과 `results/39_final_choice.log`. 표는 발행월 포트폴리오 Sharpe(국채 허들)이고 괄호 안은 SE다.

| 승인비율 | V1 기대수익 순 | V2 부도확률 낮은 순 |
|---|---|---|
| 10% | 2.55 (0.47) | **3.82** (0.84) |
| 20% | 2.75 (0.62) | 3.61 (0.79) |
| 30% | 2.91 (0.69) | 3.34 (0.83) |
| 40% | 3.01 (0.69) | 3.17 (0.80) |
| 50% | 3.00 (0.70) | 3.12 (0.79) |
| 60% | 3.04 (0.71) | 3.11 (0.78) |
| 70% | 3.05 (0.73) | 3.07 (0.76) |
| 80% | 3.01 (0.71) | **3.06** (0.74) ← 선택 |
| 90% | 2.93 (0.69) | 2.98 (0.71) |

- 최고는 V2 10%(3.82, SE 0.84)이고, 기준선은 3.82 − 0.84 = 2.98이다. V1 10~30%와 두 전략의 90%를 뺀 13개 후보가 기준선 이상이다.
- 그중 승인비율이 가장 큰 80%에서 V2(3.06)가 V1(3.01)보다 높다.
- **최종 제안은 V2 부도확률 낮은 순, 승인 80%다.**
- 같은 비율 무작위는 2.72, 전부 승인은 2.71이다. 선택안에서 무작위를 뺀 값은 +0.34(90% 구간 0.30~0.55)다.
- 허들별 선택안 Sharpe는 국채 +1%p 2.51, +2%p 1.94, BAA 0.84다. BAA 기준에서는 V1 30%(1.29)보다 낮다.
- V3 단순 규칙(도전자)은 80%에서 3.07로 선택안과 비슷하다. 최고는 20%의 3.91이다.

**읽는 법.** SE가 0.7~0.8로 커서, 48개월로는 전략과 승인비율 사이 Sharpe 차이 대부분이 통계적으로 구분되지 않는다. 1-SE 규칙은 그럴 때 많이 승인하는 쪽을 고른다. 그래서 "Sharpe가 가장 높은 조합"이 아니라 "구분되지 않는 조합 가운데 가장 많이 사는 조합"이 제안이 됐다. 대신 무작위와의 차이(같은 달끼리 짝지어 비교)는 구간이 좁고 0보다 크다.

## 보고 추가 v2.2.1 (2026-11-16, test 전, 최종 제안과 판정 불변, 태그 `test-protocol-v2.2.1`)

팀원 검토(이교민, 2차)에서 다음 순서를 제안했다. "둘 다 나쁜 조합은 빼고, 둘 다 좋아지는 조합이 있는지 찾고, 양립이 안 되는 지점에서만 무게를 정하자." 그래서 수익·흔들림 파레토 점검을 train에서 해 보고(41단계), test에서는 보고만 하도록 추가한다.

- **축:** 발행월 포트폴리오의 평균 초과수익(수익)과 표준편차(흔들림). 포트폴리오 Sharpe는 이 둘의 비율이므로 세 번째 목표가 아니다.
- **비교는 같은 승인비율 안에서 한다.** 승인비율을 올리면 국채 대신 대출에 넣는 돈이 늘어 평균과 표준편차가 함께 거의 비례해 커진다(10%: 0.5%p·0.13 → 90%: 4.7%p·1.57). 비율이 다른 조합끼리 비교하면 "무엇을 샀나"가 아니라 "얼마나 샀나"를 비교하게 된다. 비율 사이의 선택은 v2.2의 1-SE 규칙이 맡는다.
- **H13(보고):** test에서 같은 승인비율의 V1, V2, V3, 무작위 사이 지배 관계를 표로 내고, 최종 제안(V2 80%)이 지배당하는지 적는다. 지배당해도 제안은 바꾸지 않는다(해석 규칙 9, 10과 같은 이유).

**train 결과(41단계, 증거 아님):**
- 모델 규칙(V1, V2)이 무작위보다 수익과 흔들림 둘 다 나쁜 승인비율은 하나도 없었다.
- V1과 V2는 어느 비율에서도 서로를 지배하지 않았다. V1은 수익이 높고, V2는 흔들림이 작다. **두 모델 규칙 사이에는 진짜 맞교환이 있다.**
- V3 단순 규칙은 30~50%에서 V2를 지배했다(수익이 더 높고 흔들림이 더 작다). 즉 "세 마리를 함께 잡는 조합"의 후보는 사후 규칙에서만 나왔다. test의 H7과 H13으로 확인한다.
- 최종 제안 V2 80%는 V3를 포함해도 지배당하지 않는다(경계 위).
