# test 평가 고정 프로토콜 v2.1 (v2 개정)

공식 test 데이터를 받기 **전에** 작성하고 커밋했다(git 태그 `test-protocol-v2.1`).
v1(`docs/test_protocol.md`)과 v2(`docs/test_protocol_v2.md`)는 그대로 두고, 이 문서에 적은 것만 바꾼다. 바뀌지 않은 항목은 v2를 따른다.

실행: `python scripts/35_test_evaluate_v2.py <test 파일>` (v1 표와 판정을 먼저 계산하고 v2.1을 덧붙인다)
예행연습: `python scripts/35_test_evaluate_v2.py --dry-run`

## 왜 개정하나

v2 고정 이후 외부 검증(37단계)과 재계산(38단계)에서 두 가지가 드러났다. test 결과를 보기 전이므로 이탈이 아니라 개정으로 처리한다.

1. **승인 컷 단위:** v2는 발행연도마다 상위 q를 잘랐다. 그러면 달마다 승인 금액이 들쭉날쭉해 포트폴리오 Sharpe가 왜곡되고(기대수익 순 2.46 vs 발행월 단위 2.91), 12월 대출까지 본 뒤 1월 승인을 정하는 셈이라 실전에서 쓸 수 없다.
2. **허들 의존:** "안정성은 부도확률 순이 1위"는 국채 기준에서만 맞고, BAA 기준이면 기대수익 순이 수익·Sharpe 모두 1위다.

## 바뀌는 것

| 항목 | v2 | v2.1 |
|---|---|---|
| V0·V1·V2 승인 컷 | 발행연도마다 상위 q | **발행월마다 상위 q** |
| V3·V4 승인 컷 | 발행연도 × 등급 | **발행월 × 등급** |
| 포트폴리오 지표의 허들 | 국채 | 국채(판정용) + **국채 +1%p, +2%p, BAA**(보고) |
| H6 두 축 | 국채 기준, 30%·50% | 같음(발행월 컷으로 계산) |
| H7 단순 규칙 | V3가 V2보다 Sharpe와 수익 모두 높음 | **V3가 V1·V2보다 Sharpe가 높고, V2보다 수익이 높음**(국채, 30%·50% 모두) |
| H9 허들 의존(신규) | 없음 | **BAA 허들, 승인 30%에서 V1이 V2보다 포트폴리오 Sharpe와 초과수익 모두 높음** |
| 결과 폴더 | results/test_v2/ | results/test_v2_1/ |

H5(등급 안 신호, 롱숏은 원래 발행월 × 등급 단위), H8(세 Sharpe 정의), 위약 점검, 해석 규칙 1~5는 v2와 같다.

## 해석 규칙에 더하는 것

6. **허들은 판단의 문제다.** 안정성 1위는 허들에 따라 바뀔 수 있으므로 허들 4단계 결과를 모두 보고한다. 국채 기준 결과만으로 "안정성은 부도확률 순"이라고 쓰지 않는다.
7. **H7은 사후 선택 규칙의 검증이다(v2와 같음).** 지지되지 않으면 그대로 보고한다.

## 예상(train 2013~16, 이미 본 데이터라 증거 아님, 38단계)

승인 30%, 발행월 컷: 포트폴리오 Sharpe(국채) 단순 규칙 3.82, 부도확률 순 3.34, 기대수익 순 2.91, 무작위 2.69. BAA 기준 기대수익 순 1.29 > 부도확률 순 0.92.
