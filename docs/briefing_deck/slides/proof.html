"우연 아니냐"는 질문에 하나씩 답했다

의심한 실험결론
운이 좋았던 것 아닌가시드 여러 개, 정답을 섞은 가짜 모델, 발행월 단위 재표본(1만 번)우연 아님. 가짜 모델은 0 근처
모델 덕 아닌가17종 비교(Lasso, 랜덤포레스트, XGBoost, CatBoost 등)바꿔도 거의 같음
피처·결측 처리 덕 아닌가새 피처 6종, 결측 처리 9종 비교거의 차이 없음
채점이 편향되지 않았나다 끝난 대출을 일부러 일찍 잘라 채점착시 발견, test 읽는 법을 미리 정함
미래 정보가 새지 않았나컬럼마다 시점 점검, 약한 누수 후보 제거결과 동일

모든 판정 기준은 결과를 보기 전에 적어 두었고, 틀린 판단도 기록에 남겼다.

과녁을 먼저 그리고 화살을 쏜 셈입니다. 결과를 본 뒤에 기준을 정하면 무엇이든 성공으로 만들 수 있기 때문입니다. 실제로 처음 판단이 틀린 경우가 여러 번 있었고, 그때마다 정정 기록을 남겼습니다. 이 기록 자체가 신뢰의 근거입니다.
