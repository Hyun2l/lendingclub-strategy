# 연구 노트

`decisions.md`가 "무엇을 골랐나"라면, 이 문서는 "무엇을 시도했고, 무엇이 틀렸고, 무엇을 버렸나"를 남긴다.
보고서나 논문을 쓸 때 근거, 한계, 정직성 서술의 원천으로 쓴다. 새 실험이 끝날 때마다 해당 표에 한 줄씩 추가한다.

기본 평가 조건(달리 적지 않으면): 2013~2016년 발행 36개월 종결 대출, 연도별 1월 1일 기준 시점 학습,
발행월 코호트 IRR(투자자 수수료 1% 차감), 비교 기준은 발행월·만기 맞춘 미 국채(GS3/GS5).

## 2. 시도했지만 실패했거나 버린 것

| 시도 | 결과 | 판단 | 배운 점 |
|---|---|---|---|
| AUC를 올리는 하이퍼파라미터 튜닝 계획 | 실행 전 중단 | 버림 | 과제 목표는 정확도가 아니다 |
| 생존모형으로 진행 중 대출 활용 | 단순 PD 모델을 이기지 못함 | 버림 | 수준 편향이 있어도 순위는 크게 안 무너진다 |
| μ/E[e²] 승인 규칙(Sharpe 최적화 조건에서 유도) | μ/σ와 사실상 같은 성능 | "새 규칙" 주장 철회 | 이론적 최적이 실용적 차이를 보장하지 않는다 |
| 확률 보정 3종(단순, 만기 도달, 생존분석 이동) | 모두 수준을 못 고침, 일부는 악화 | 버림 | 과거 기반 보정은 추세 변화를 못 따라간다 |
| 장부가 월별 계좌 수익률로 위험 측정 | 최악의 달도 플러스, 연 Sharpe 6~9 | 버림 | 시가 평가 없이는 월별 위험을 못 잰다 |
| RAROC를 주 지표로 | 기본 가정에서 99% 승인, 결과가 가정에 좌우 | 주 지표에서 제외 | 무담보 대출 마진에 비해 바젤 자본이 작다 |
| 포트폴리오 효용(확실성 등가) | 위험회피 50까지도 최적은 전부 승인 | 결정 지표로는 버림, 비판 근거로 유지 | 분산된 포트폴리오에서는 규모가 위험보다 중요하다 |
| 모델 없는 세부등급 규칙 | 무작위와 거의 같음 | 버림 | 등급 사이에는 고를 정보가 적다 |
| 피처 엔지니어링 6종(상환 부담, 신용 이력 개월, 근속 연수, 우편번호 부도율, FICO 평균, 전체 묶음) | 선별 가치 변화 -0.0001~+0.0002, 시드 차이(최대 0.0009)와 노이즈 피처 범위 안 | 모두 기각 | 등급 안 정보가 있어도 트리 모델이 원본 변수(소득, 상환액, 대출액, 주)에서 이미 잡는다 |
| 피처 엔지니어링 대신 방법 검증을 했어야 했던 요청 오해 | 사용자가 요청한 것은 새 비교 방법의 검증이었음 | 14단계에서 다시 수행 | 요청 범위를 먼저 확인한다 |
| 하이일드 지수 비교 | FRED가 2023년 이후만 제공 | 불가 | 데이터 접근성도 설계 조건이다 |

## 5. 데이터 엿보기와 다중 검정 기록

- 2013~2016년 평가 구간을 7단계부터 계속 재사용했다. 규칙·지표·피처를 고를수록 이 구간에 맞춰질 위험이 커진다.
- 11단계부터는 판정 기준을 실험 전에 정해 적었다.
- 12단계 EDA는 평가 구간 결과를 보지 않도록 2007~2012년 대출만 썼다.
- 14단계는 처음으로 2017년 발행분을 보류 구간으로 썼다(종결 77%, 종결 편향 있음). 이후 이 구간도 '본 구간'이 되었으므로 최종 판단용으로는 공식 test만 남는다.
- 13단계는 피처 후보 6개 + 대조군 3개(시드, 노이즈, FICO 평균)를 같은 구간에서 비교했다. 통과한 후보가 없어 선택 편향 문제는 생기지 않았다.
- 지금까지 비교한 승인 규칙·지표 조합은 대략 60개 이상이다. 최종 보고에서는 시도한 수를 함께 밝힌다.
- **제안:** 최종 판단용으로 한 번도 보지 않은 구간을 남긴다(공식 test 데이터, 또는 2017년 발행분을 종결 편향을 감안해 사용).
