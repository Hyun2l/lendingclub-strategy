# 연구 노트

`decisions.md`가 "무엇을 골랐나"라면, 이 문서는 "무엇을 시도했고, 무엇이 틀렸고, 무엇을 버렸나"를 남긴다.
보고서나 논문을 쓸 때 근거, 한계, 정직성 서술의 원천으로 쓴다. 새 실험이 끝날 때마다 해당 표에 한 줄씩 추가한다.

기본 평가 조건(달리 적지 않으면): 2013~2016년 발행 36개월 종결 대출, 연도별 1월 1일 기준 시점 학습,
발행월 코호트 IRR(투자자 수수료 1% 차감), 비교 기준은 발행월·만기 맞춘 미 국채(GS3/GS5).

## 2. 시도했지만 실패했거나 버린 것

| 시도 | 결과 | 판단 | 배운 점 |
|---|---|---|---|
| AUC를 올리는 하이퍼파라미터 튜닝 계획 | 실행 전 중단 | 버림 | 과제 목표는 정확도가 아니다 |
| 생존모형으로 진행 중 대출 활용 | 단순 PD 모델을 이기지 못함 | 버림 | 수준 편향이 있어도 순위는 크게 안 무너진다 |
| μ/E[e²] 승인 규칙(Sharpe 최적화 조건에서 유도) | μ/σ와 사실상 같은 성능 | "새 규칙" 주장 철회 | 이론적 최적이 실용적 차이를 보장하지 않는다 |
| 확률 보정 3종(단순, 만기 도달, 생존분석 이동) | 모두 수준을 못 고침, 일부는 악화 | 버림 | 과거 기반 보정은 추세 변화를 못 따라간다 |
| 장부가 월별 계좌 수익률로 위험 측정 | 최악의 달도 플러스, 연 Sharpe 6~9 | 버림 | 시가 평가 없이는 월별 위험을 못 잰다 |
| RAROC를 주 지표로 | 기본 가정에서 99% 승인, 결과가 가정에 좌우 | 주 지표에서 제외 | 무담보 대출 마진에 비해 바젤 자본이 작다 |
| 포트폴리오 효용(확실성 등가) | 위험회피 50까지도 최적은 전부 승인 | 결정 지표로는 버림, 비판 근거로 유지 | 분산된 포트폴리오에서는 규모가 위험보다 중요하다 |
| 모델 없는 세부등급 규칙 | 무작위와 거의 같음 | 버림 | 등급 사이에는 고를 정보가 적다 |
| 피처 엔지니어링 6종(상환 부담, 신용 이력 개월, 근속 연수, 우편번호 부도율, FICO 평균, 전체 묶음) | 선별 가치 변화 -0.0001~+0.0002, 시드 차이(최대 0.0009)와 노이즈 피처 범위 안 | 모두 기각 | 등급 안 정보가 있어도 트리 모델이 원본 변수(소득, 상환액, 대출액, 주)에서 이미 잡는다 |
| 피처 엔지니어링 대신 방법 검증을 했어야 했던 요청 오해 | 사용자가 요청한 것은 새 비교 방법의 검증이었음 | 14단계에서 다시 수행 | 요청 범위를 먼저 확인한다 |
| 하이일드 지수 비교 | FRED가 2023년 이후만 제공 | 불가 | 데이터 접근성도 설계 조건이다 |
| 결측 처리 방식 비교를 모델 비교보다 나중에 함 | 사용자 지적으로 모델 비교를 멈추고 결측 처리부터 결정(22단계) | 순서 바로잡음 | 전처리 결정은 모델 비교 전에, 근거와 함께 고정한다 |
| 로지스틱 결측 처리 1차 비교(22단계) | 2016년 AUC 0.508. 원인은 결측 처리가 아니라 학습 시점에 없던 변수의 표준화 폭발 | 가용성 규칙·분위 자르기 추가 후 재비교 | 결과가 이상하면 판정 전에 원인부터 찾는다 |
| LightGBM 튜닝(학습 데이터 안 AUC로 격자 탐색), HistGradientBoosting(23단계) | 선별 가치 0.86%p, 0.63%p로 기본 LightGBM(1.03%p)보다 낮음. 2016년 Brier 약 0.14 | 기각 | AUC로 튜닝하면 부도확률 수준이 나빠질 수 있다 |
| CatBoost(24단계) | 2016년 평균 부도확률 3.6%(실제 15.9%), 선별 가치 -0.12%p | 기각 | 가용성 규칙으로 정상화(0.93%p)되지만 여전히 LightGBM보다 낮음 |

| 로지스틱은 결측 처리를 바꿔도 성능이 낮다(22단계 1차 결과) | 원인은 시점별 변수 가용성. 규칙을 넣자 2016년 AUC 0.508 → 0.678 | 표준화 값 분포 점검 |
| 결측 처리는 이미 정했다(LightGBM 결측 그대로) | 무작위 분할 실험 하나로 암묵적으로 쓰고 있었을 뿐, 정식 결정·기록이 없었음 | 사용자 지적 |
| CatBoost 붕괴는 새 컬럼이 '조기 종결' 대리 변수가 된 탓이다(24단계 1차 가설) | 새 컬럼 유무에 따른 학습 부도율이 17.2% vs 17.6%로 거의 같아 가설 기각. 기제는 미확인, 해법(가용성 규칙)만 확인 | 24b 진단 |
| 선형 대표는 Lasso(23단계) | Lasso + 피처가 사전 기준을 통과해 대표가 바뀜. 23단계의 동점 처리 규칙은 사전에 정하지 않았음 | 24단계 |
| 부도확률 수준이 선별 가치를 좌우한다(24단계 C19 초안) | 2013년 LightGBM은 PD를 절반으로 과소추정해도 선별 가치 최고. 극단적 붕괴만 문제 | 25단계 연도별 평균 PD 점검 |
| 2017년 보류 구간에서는 부도확률 순위가 더 낫다(14단계) | 전부 끝난 2013~15년 대출을 같은 방식으로 자르면 같은 역전이 재현됨. 종결 편향의 산물 | 26단계 시뮬레이션 |
| Sharpe는 승인비율에 끌려가므로 주 지표로 부적합하다 | 대출 건별 Sharpe에만 맞는 말. 발행월별 포트폴리오 Sharpe는 승인비율이 상쇄되며, 그 기준으로는 보수적 선별이 더 높다(팀원 제안서 지적) | 30단계 |

## 5. 데이터 엿보기와 다중 검정 기록

- 2013~2016년 평가 구간을 7단계부터 계속 재사용했다. 규칙·지표·피처를 고를수록 이 구간에 맞춰질 위험이 커진다.
- 11단계부터는 판정 기준을 실험 전에 정해 적었다.
- 12단계 EDA는 평가 구간 결과를 보지 않도록 2007~2012년 대출만 썼다.
- 14단계는 처음으로 2017년 발행분을 보류 구간으로 썼다(종결 77%, 종결 편향 있음). 이후 이 구간도 '본 구간'이 되었으므로 최종 판단용으로는 공식 test만 남는다.
- 13단계는 피처 후보 6개 + 대조군 3개(시드, 노이즈, FICO 평균)를 같은 구간에서 비교했다. 통과한 후보가 없어 선택 편향 문제는 생기지 않았다.
- 지금까지 비교한 승인 규칙·지표 조합은 대략 60개 이상이다. 최종 보고에서는 시도한 수를 함께 밝힌다.
- **제안:** 최종 판단은 한 번도 보지 않은 공식 test 데이터로 한다. 2017년 발행분은 14단계에서 이미 사용했다.
- 18~19단계는 후보 A의 반대 질문을 같은 2013~16년 구간에서 탐색했다(기준 사전 고정). 추가 탐색을 거듭할수록 이 구간에 맞춰질 위험이 커지므로 여기서 탐색을 멈추고 test를 기다린다.
- 20~32단계(EDA, 결측 방침, 모델 비교 약 17종, 부트스트랩, 종결 편향 시뮬레이션)는 사용자 요청으로 같은 2013~16년 구간을 다시 썼다. 판정 기준은 실험 전에 정했고, 결과가 좋아도 test 프로토콜의 모델은 바꾸지 않는다.
- 2026-11-09: test 평가 규칙을 `docs/test_protocol.md`(v1)로 고정하고 태그 `test-protocol-v1`을 달았다. 예행연습은 train의 30%를 떼어 코드가 끝까지 도는지만 확인한 것이다. 이미 본 데이터라 가설의 증거로 쓰지 않는다.

## 6. 열린 질문

- CatBoost가 학습 때 거의 비어 있던 컬럼에서 수준이 무너진 정확한 기제는? 공식 test에서 LightGBM도 같은 위험이 있는지 가용성 규칙 적용 결과를 함께 보고해 확인한다.

- 신용 악화를 거시 변수(실업률 등)로 설명하고 예측할 수 있는가?
- 60개월 대출에서도 C2, C6, C7이 유지되는가?
- 조기상환 위험을 따로 모델링하면 선별 가치가 커지는가?
- 공식 test 데이터의 구성: 조교 답변(2026-11-09)에 따르면 일주일 안에 배포되고, 상환 결과 컬럼이 포함되며, 진행 중 대출은 없을 것으로 보인다. 발행 기간 분포는 받은 뒤 `05_inspect_test.py`로 확인한다.
- 최종 평가 방식과 제출 형식은 아직 답을 받지 못했다.
- test에 진행 중 대출이 없다면 최근 발행분은 '일찍 끝난 대출'만 남아 부도가 과대 대표된다. test 평가는 발행연도별로 나눠 보고하고, 2013~2016년 구간을 따로 보여야 한다.
