# test 평가 고정 프로토콜 (v1)

이 문서는 공식 test 데이터를 받기 **전에** 작성하고 커밋했다(git 태그 `test-protocol-v1`).
test 결과를 본 뒤에는 이 문서의 가설, 규칙, 지표, 성공 기준을 바꾸지 않는다.
바꿔야 할 사정이 생기면 문서를 고치지 않고 '이탈 기록'에 이유와 함께 남긴다.

실행: `python scripts/15_test_evaluate.py <test 파일>`
예행연습: `python scripts/15_test_evaluate.py --dry-run` (train의 30%를 가짜 test로 떼어 같은 코드를 돌림)

## 1. 먼저 하는 점검 (결과를 보기 전)

`scripts/05_inspect_test.py`로 컬럼, 결과 상태, 발행연도 분포, train과의 id 중복을 확인한다.

| 점검 결과 | 처리 |
|---|---|
| 상환 결과 컬럼(`total_pymnt`, `last_pymnt_d`) 없음 | 수익 평가는 하지 않고, 승인 목록과 예측 확률만 만든다 |
| 진행 중 대출(Current, Late 등)이 있음 | 평가는 종결 대출(Fully Paid, Charged Off, Default)만 쓰고, 진행 중 비율을 함께 보고한다 |
| train과 id가 겹침 | 겹친 대출은 평가에서 빼고 건수를 보고한다 |

## 2. 고정한 설정

| 항목 | 값 |
|---|---|
| 학습 데이터 | 공식 train만 사용. test의 정보는 학습, 보정, 임계값 선택에 쓰지 않는다 |
| 학습 방식 | 시점 학습: 발행연도 Y의 test 대출은 Y년 1월 1일까지 확정된 train 대출로 학습한 모델로 예측(부도 확정은 마지막 납부 + 5개월) |
| 모델 | LightGBM, `src/lc/models.py`의 고정 파라미터, 시드 0~4 다섯 개의 예측 확률 평균 |
| 특성 | `src/lc/data.py`의 기본 101개(피처 엔지니어링 없음) |
| 기대수익 | (1 - PD) x 약정 금리 - PD x LGD, LGD는 그 시점 확정 부도 대출 평균 |
| 비교 기준 | 발행월·만기 맞춘 미 국채(GS3/GS5). 보조로 회사채 BAA |
| 수익률 | 발행월 코호트 IRR, 투자자 수수료 1% 차감 |
| 주 평가 표본 | test의 2013~2016년 발행 36개월 종결 대출 |
| 보조 평가 표본 | 같은 기간 60개월 대출, 2017~2018년 발행 36개월 대출(종결 편향 있음) |

## 3. 고정한 승인 규칙

| 이름 | 규칙 | 역할 |
|---|---|---|
| R0 | 전부 승인 | 기준선 |
| R1 | 기대수익 > 만기 국채 | **주 승인 규칙**(제출용 승인 목록이 필요하면 이것). 시점 학습 모델이 있는 2013~2018년 발행분만 판단하고, 그 밖의 연도는 '판단 없음'으로 둔다 |
| R2 | 연도별 기대수익 상위 50% | 성과 귀속 분석용 |
| R3 | 연도별 부도확률 하위 50% | 부도 기준과 비교용 |

## 4. 가설과 성공 기준 (미리 정함)

| 가설 | 지표 | 지지 기준 |
|---|---|---|
| H1 성과 귀속: 모델의 추가 수익은 주로 같은 등급 안의 선별에서 나온다 | R2의 브린슨 분해(세부등급 35개 기준) | 2013~16년 통합 '등급 안 선별' > 0 이고 '등급 배분'보다 크며, 4개 연도 중 3개 이상에서 선별 > 0 |
| H2 선별 가치: 기대수익 순위는 무작위보다 더 번다 | 선별 곡선(승인비율 10~90%) 무작위 대비 면적 | 발행월 부트스트랩 95% 구간 하한 > 0 |
| H3 국채 대비: 전부 승인도 국채보다 높다 | R0의 발행월별 IRR - 국채 | 발행월의 90% 이상에서 양수 |
| H4 회사채 대비: 선별하면 회사채 대비 성과가 나아진다 | R1 vs R0의 발행월별 IRR - BAA | R1의 BAA 이하 발행월 수 < R0의 수 |

지지 기준을 넘지 못하면 그 가설은 test에서 '지지되지 않음'으로 그대로 보고한다.

## 5. 보고할 표 (모두 계산, 고르지 않음)

1. 점검 결과(1절)
2. 규칙 R0~R3별: 승인비율, 코호트 IRR, 국채 대비 초과수익, 국채 이하 발행월 수, 회사채 대비 초과수익, 회사채 이하 발행월 수, 승인 부도율, 하위 5% 평균, 과제식 Sharpe(부도=0, rf 5%)
3. H1: 연도별·통합 브린슨 분해(등급 7개, 세부등급 35개)
4. H2: 기대수익 순위와 부도확률 순위의 선별 가치와 95% 구간
5. 보조 표본(60개월, 2017~2018년)의 같은 표
6. 참고: 전체 train으로 한 번에 학습한 모델(미래 정보 포함)로 같은 표. 시점 학습과의 차이를 보이기 위한 것

## 6. 하지 않는 것

- test를 본 뒤 파라미터, 특성, 임계값, 표본 정의를 바꾸기
- 여러 규칙 중 test에서 좋아 보이는 것을 골라 '주 규칙'으로 바꾸기
- 2절과 다른 분석을 '확증'처럼 보고하기(추가 분석은 모두 '탐색'으로 표시)
