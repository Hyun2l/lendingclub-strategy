# 검토자용 변경 요약 (2026-11-16, 1~38단계)

다른 사람이나 AI가 이 프로젝트를 검토할 때 먼저 읽는 문서다. 자세한 근거는 `docs/decisions.md`(단계별 결정), `docs/research_log.md`(주장 장부 C1~C36, 실패, 정정)에 있다.

## 1. 지금 주장하는 것 (조건 포함)

표본: 2013~16년 발행 36개월 종결 대출 522,218건(48개 발행월), 시점 학습 LightGBM, 투자자 수수료 1%. 승인 컷은 **발행월 단위**, 동점은 무작위로 끊음(38단계).

| 주장 | 숫자 | 성립 조건 |
|---|---|---|
| 기대수익 순위는 무작위보다 더 번다 | 선별 가치 +1.07%p(90% 구간 0.94~1.21), 48개월 전부 양수 | 국채 기준. 허들을 올려도 수익 1위 유지 |
| 같은 등급 안에 돈이 되는 정보가 있다 | 등급 중립 롱숏 +2.38%p, 48/48개월, 위약 0 | 롱숏은 발행월×등급 단위. 해마다 줄지 않음, 조각 대출·60개월·가격 정보 없는 모델에서도 유지 |
| 안정성(포트폴리오 Sharpe) 1위는 허들에 따라 바뀐다 | 승인 30%: 국채 기준 부도확률 순 3.34 > 기대수익 순 2.91, BAA 기준 기대수익 순 1.29 > 부도확률 순 0.92 | 허들 = 투자자의 요구수익률. 국채+2%p에서 둘이 비슷 |
| 단순 규칙(발행월·등급마다 최근 24개월 개설 계좌가 적은 순)이 Sharpe 1위 | 승인 30%: 국채 3.82, +1%p 3.18, +2%p 2.54, BAA 1.45로 네 허들 모두 1위. 수익은 기대수익 순과 거의 같음(1.84 vs 1.88) | **사후 선택**(33단계에서 신호를 보고 고름). test 규칙에 미리 고정한 후보 |
| 36개월 고위험 등급(E~G)은 금리가 위험을 못 메웠다 | 등급별 Sharpe A 5.2 → E 0.6 | 36개월만. 60개월은 반대. 그 등급 20건 미만인 달은 제외한 값 |

## 2. 철회하거나 범위를 좁힌 것

## 3. 코드상의 선택(검토 때 알아야 할 것)

- **승인 컷 단위:** 30~36단계 스크립트와 `scripts/35_test_evaluate_v2.py`의 `top()`/`by_year_top()`은 **발행연도 단위**다. 38단계부터 발행월 단위로 다시 계산했다. 보고서(`docs/notes/LC_report.pdf`) 7장 표와 test 규칙 v2는 아직 연도 단위 값이다(수정 대기).
- **선별 가치(23·25단계 `curve`)**도 연도 단위 컷이다. 발행월 단위로 바꾸면 1.03 → 1.07%p로 거의 같다.
- **허들:** 기본은 발행월·만기에 맞춘 미 국채(GS3/GS5). BAA는 `src/lc/benchmarks.py`.
- **시점 학습:** `asof.known_at`은 기준월(1월)에 마지막 납부한 대출까지 포함한다(1개월 미래, 영향 작음). 학습에 36·60개월 대출이 함께 들어간다.
- **등급별 표:** 그 등급 대출 20건 미만인 달은 뺀다(33단계).
- **특성:** 기본 101개에 `funded_amnt_inv`(투자 모집 후 확정) 포함. 빼도 결과 같음(28단계).
- **무작위 분할 AUC 0.73:** 2007~2020년 전체 종결 대출 기준으로 보인다. 같은 표본(2013~16년 36개월)이면 약 0.70(외부 검증 값).

## 4. 아직 안 한 것 / 열린 문제

1. 보고서·팀 안내서·test 규칙을 위 정정에 맞춰 수정(**test 전 v2.1 고정 필요**: 발행월 컷, 허들 민감도 명시).
2. p 과소추정의 원인(직전 해 발행분 중 조기상환만 끝난 표본)을 보고서 5장에 반영.
3. 공정성(거주 주가 대리변수인지), 오류 분석, 슬라이스(목적·금액), 적대적 검증(train vs test 분포).
4. 단순 규칙은 사후 선택이므로 test에서만 확인 가능.
5. 같은 2013~16년을 38단계째 사용(데이터 엿보기). 최종 판단은 공식 test.
