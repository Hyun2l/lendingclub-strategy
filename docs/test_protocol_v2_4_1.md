# test 평가 고정 프로토콜 v2.4.1 (보완: 모델 없는 기준선 판정 H17, 보고 항목)

공식 test 데이터를 열기 **전에** 작성했다(2026-11-24). 커밋한 뒤 git 태그 `test-protocol-v2.4.1`을 붙인다.

v2.4의 주 지표(건별 Sharpe), 후보, 선택 결과(**V2 부도확률 낮은 순 40%**), 주 판정 H14, 해석 규칙 9–12는 **바꾸지 않는다.** 이 문서는 판정 하나(H17)와 보고 항목만 더한다.

## 왜 더하나

- H14는 같은 비율 **무작위**와만 비교한다. 부도가 적은 대출을 고르는 규칙이면 모델 없이도 통과할 수 있어, 통과해도 "모델이 필요했다"는 증거가 되지 않는다.
- 포트폴리오 Sharpe에서는 금리 낮은 순(모델 없음)이 V2와 같았다(43단계). 건별 Sharpe에서도 그런지 test에서 확인해야 한다.
- 이 지표를 이론상 가장 높이는 순서(V5)가 V2보다 나은지도 보고한다.

## 1. H17 모델 기여 (2차 판정, 보고 문장을 정함)

- **기준:** V2 40% 건별 Sharpe − 금리 낮은 순 40% 건별 Sharpe의 95% 블록 부트스트랩 구간(발행월 6개월 블록, 2000회, seed 2026) 하한 > 0.
- 금리 낮은 순: 발행월마다 금리 r이 낮은 순으로 40%(동점은 1e-6 무작위, seed 11).
- H17은 제안을 바꾸지 않는다. 결과에 따라 아래 문장 중 하나를 쓴다.

| H14 | H17 | 보고 문장 |
|---|---|---|
| 통과 | 통과 | 모델로 고른 V2가 무작위와 금리표 모두보다 건별 Sharpe가 높았다 |
| 통과 | 실패 | 무작위보다는 높았지만 금리표로도 비슷하게 얻을 수 있었다. 모델의 기여는 확인하지 못했다 |
| 실패 | – | 제안 철회. 원인은 v2.3.1 점검표로 가설로만 보고 |

## 2. 보고 항목 (판정과 제안을 바꾸지 않음)

- 금리 낮은 순, 세부등급 좋은 순(같은 세부등급 안은 무작위) × 승인 10–90%의 건별 Sharpe.
- **V5 = μ / E[x²]** 순 × 10–90%와 자기일관 기준선. μ = s = (1−p)r − p·LGD − tb, E[x²] = (1−p)(r−tb)² + p(LGD+tb)². 대출 하나를 더할 때 건별 Sharpe가 오르는 조건이 μ/E[x²] > S₁/(2S₂)라서, 이 지표의 이론상 최적 순서다. 자기일관 기준선은 c = S₁/(2S₂)를 예측 모멘트로 반복해 풀고 μ/E[x²] > c인 대출을 승인한다.
  - p는 모델 그대로(주)와 재보정(발행연도마다 평가 대출 평균 p를 그해 학습 표본 부도율에 맞춘 배율)을 함께 보고한다.
- V1 기대수익 순: 수익이 목표인 투자자를 위한 대안(선별 가치 H2 포함).
- 해석 규칙 13: 보고 항목이 V2보다 좋아도 제안을 바꾸지 않는다(v2.4 규칙 10과 같음).
